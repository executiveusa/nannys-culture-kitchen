# Nanny's Gauntlet Plan

## Independent review roles
1. Conversion prosecutor — can a worksite coordinator act immediately?
2. Krug clarity reviewer — what requires unnecessary thought?
3. Creative director — could this belong to another plant-based restaurant?
4. Slop/taste hunter — locate generic AI patterns and decoration without purpose.
5. Mobile director — composition, touch, crop, forms, overflow.
6. Accessibility reviewer — semantics, focus, labels, contrast, motion.
7. Truth/evidence auditor — compare public claims to `10_strategy/evidence-ledger.md`.
8. Production engineer — build, routes, errors, performance, deployment revision.
9. Security/privacy reviewer — public form and data handling.
10. Sovereignty reviewer — repo, Hostinger, Convex, credentials, rollback.

## Hard gates
- two-second test: pass
- one dominant conversion: pass
- lead success path: real
- unsupported public claims: 0
- P0: 0
- P1: 0
- broken public routes: 0
- mobile overflow: 0
- critical accessibility failures: 0
- rollback: documented
